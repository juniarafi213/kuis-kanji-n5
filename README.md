# Kuis Interaktif JLPT N5 (Bab 1–11)

Aplikasi kuis interaktif untuk latihan mandiri Kanji JLPT N5 lengkap dengan cara baca (*furigana/hiragana*), arti bahasa Indonesia, sistem streak, mode review soal salah, dan filter bab.

## Cara Menggunakan
Buka file `index.html` langsung di browser, atau akses secara online melalui GitHub Pages.
